MOSS-Image models

        
Each model is a 10 GB transformer; the first download also brings the Qwen3.5 9B text encoder and the VAE (17 GB), which Base and SFT share. Downloads resume if stopped.

        
    
        
      
      
      
      
      
        
      Model folders
      
        
      Folders searched for models besides the download folder: a folder holding MOSS-Image-SFT/-style model folders (e.g. venno-trainer's models folder) or single-file transformers. One per line.
      
        
        
      
      
      
    
      
    
      
      
      
        
      LoRA folders
      
        
      Folders listed in the LoRA picker (sub-folders too), besides . Add your trainer's output folder to test each epoch as it is saved; press ⟳ in the top bar to pick up new files.
      
        
        
      
      
      
    
      
    
      
      
      
        
      Memory
      
        
        
        
        
      Either way the 9B text encoder stays in system RAM (about 17 GB) and only visits the graphics card a layer at a time when a new prompt is encoded; encoded prompts are reused. Applies from the next picture, no restart needed.
